PicUp v0.0.3

## 新增
- 应用图标改用 `logo.png` 生成：自适应图标 + 主题单色（monochrome）支持，图形占图标可见区域约 60%，白底。

## 改进
- 编辑自定义格式：**删除 / 取消 / 保存** 放在同一行，三等分等距；删除用 error 色文字。
- 所有三点菜单统一 18dp 圆角，底色从纯白改为 `surfaceContainerHigh`，在浅色页面上不再像"挖了个洞"。

## 安装
- 包名 `github.wzk0.picup`，versionCode 3 / versionName 0.0.3
- 与 0.0.2 同一签名，可直接覆盖安装
- 校验：`sha256sum -c SHA256SUMS.txt`
