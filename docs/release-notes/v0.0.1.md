PicUp v0.0.1 —— 把图片和文件提交到你自己的 Git 仓库，链接直接引用。

## 支持平台（插件）
GitHub（含 Enterprise）、GitLab（含自建）、Gitee 码云、Gitea / Forgejo（自建）、Codeberg。
设置 → 插件里勾选后，添加账号时才会出现；默认只开启 GitHub。

## 主要功能
- 登录用 Personal Access Token，Android Keystore AES-GCM 加密保存在本机
- 相册多选 / 任意文件上传，串行提交；输出原格式·WebP·JPEG·PNG，质量三档，EXIF 可移除
- 路径模板（占位符 + 实时预览）、复制格式可自定义（默认 Markdown）
- 历史列表/卡片视图、搜索、多选批量删除远端、全屏预览（缩放/翻页/按格式复制）
- 固定绿色主题 / 动态取色、预测性返回、自定义 snackbar 与列表动画

## 安装
- 包名 `github.wzk0.picup`，minSdk 26 / targetSdk 36
- 首次安装即可用；**若装过调试包需先卸载**（签名不同，无法覆盖）
- 校验：`sha256sum -c SHA256SUMS.txt`

## 已知限制
- 私有仓库的 raw / jsDelivr 链接对外打不开，需要自建 CDN 反代
- 缩放上限固定 2048px；不支持 LFS，单文件上限 64MB

## 构建
本包由 GitHub Actions 在 tag 推送时构建、用仓库 secret 签名，并作为 release 资产自动发布。
