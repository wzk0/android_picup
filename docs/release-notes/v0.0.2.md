PicUp v0.0.2

## 新增
- **从剪贴板上传**：选图卡片右下角新增按钮。剪贴板是图片时按图片管线处理；是文字时弹窗让你命名，按纯文本 `.txt` 文件上传（上限 512 KB）。

## 修复
- 剪贴板里的**文字被当成图片解码**并报「无法解码这种图片」：`file://` 来源没有 MIME，改为按真实扩展名判定（新增 `UploadKinds`，覆盖无扩展名 / `archive.tar.gz` 等边界），且富文本剪贴板优先走文字分支；扩展名像图片但解码失败时退回按原样上传。
- 编辑自定义格式时「删除 / 取消 / 保存」三个按钮间距不一致：删除移入正文（error 色），操作行只剩取消/保存。
- 任意文件 / 剪贴板按钮过大遮住选图卡片内容：52dp → 42dp。
- 最近上传条目的复制格式行右边距过窄：改为左右对称 12dp。

## 多选与动画
- 勾选指示器重做：20dp、1dp 细环、半透明底，选中时描边渐变消失。
- 左侧「N 条记录」↔「取消 / 批量删除」的切换改为弹簧淡入 + 缩放，与全 App 动画语言一致。
- 批量删除按钮改用 tertiary 强调色；删除前弹窗确认；多选时返回键/返回手势只取消选择。

## 其它
- 版本 0.0.2（versionCode 2）。

## 安装
- 包名 `github.wzk0.picup`，与 0.0.1 同一签名，可直接覆盖安装。
- 校验：`sha256sum -c SHA256SUMS.txt`
