PicUp v0.0.4

## 修复
- **Gitea / Forgejo 上传的图片是 0 字节空文件**：写文件请求没有声明 `Content-Type`，`HttpURLConnection` 于是自动填成 `application/x-www-form-urlencoded`；Gitea 按这个头把 JSON 正文当表单解析，`content` / `message` / `branch` 全部取空，接口照样返回 201，最终提交出一个空文件。GitHub 与 GitLab 会嗅探正文，所以只有 Gitea 暴露了这个问题。现在 GitHub / GitLab / Gitea 三家都显式发送 `application/json; charset=utf-8`。
- 旧版本经 Gitea 传上去的空文件不会自动修复，需要在 App 里删除后重传。

## 其它
- 新增 4 项回归测试：用本地 HTTP 服务器抓真实请求，钉住三家主机写文件的请求头与 base64 正文，并覆盖「文件已存在 → POST 422 后走 PUT」的覆盖路径。
- 版本 0.0.4（versionCode 4）。

## 安装
- 包名 `github.wzk0.picup`，versionCode 4 / versionName 0.0.4
- 与 0.0.3 同一签名，可直接覆盖安装
- 校验：`sha256sum -c SHA256SUMS.txt`
